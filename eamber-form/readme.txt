=== e.Amber お問い合わせフォーム ===

電気工事の問い合わせフォーム。
「工事内容」を選ぶと、その内容に合わせた質問（エアコンなら設置階・専用コンセントの有無、
ブレーカーなら症状・止まっている範囲…）に切り替わるステップ型フォームです。
受付内容はDBに保存され、担当者へ通知します。メールアドレスの入力があった
お客様には「受付完了メール」を自動返信します（メールは任意。電話が主戦場のため）。

工事内容は9種。タイルを1タップで選ぶ形です:
   エアコン（取り付け・修理）／ブレーカーが落ちる・漏電・分電盤／インターホン／
   コンセント・スイッチ／照明・LED化／換気扇／住宅の配線・電気工事全般／
   店舗・事務所・工場の設備／その他の問い合わせ・相談

   ※タイルは絞らず9枚すべて見せています。数を減らすと「自分のが無い」と
     判断されて離脱するためで、ここの網羅性が反響数に直結します。
     「その他」は逃げ道ではなく、工事内容が決まっていない方
     （＝流入の最大勢力）に加えて、提携の営業・リピートのご連絡と
     いった工事以外の用件も取りこぼさないための枠です。

必須項目は4つだけ（工事内容・市町村・お名前・電話番号）。
市町村は山梨県27市町村＋県外の選択式です。
運営＝施工＝同じ会社の自社サイトに置く前提なので、会社紹介欄や
第三者提供の設定はありません。会社名はサイト名に一本化しています。
お客様に読ませる同意は「プライバシーポリシーに同意します」の1つだけです。


■ 導入手順
1. 「プラグイン」→「新規追加」→「プラグインのアップロード」→ この zip を
   選択してインストール →「有効化」
2. 左メニュー「電気工事反響フォーム → 設定」で以下を設定
   - 「基本設定」タブ：会社名（サイト名）／電話番号（お客様向け）／
     問い合わせメール／所在地
     ※電話番号は「お急ぎの方はお電話が早いです」としてフォームの一番上に
       表示されます（工事の問い合わせは急ぎが多く、電話が最短の導線のため）。
       受付完了メールの末尾にも入ります。
   - 送信元メール・通知先メール（担当者）
   - プライバシーポリシーURL
   - 「入力項目」タブで、項目ごとに 必須／任意／非表示 を選ぶ
3. お問い合わせページを公開する
   有効化したとき、スラッグ form の固定ページ「お問い合わせ」を
   下書きで自動作成しています（中に [eamber_form] が入っています）。
   内容を確認して公開してください。
   ※同じスラッグのページが既にある場合は、それをお問い合わせページとして使います。
   ※一度作成したあとは、消しても自動では作り直しません。
   ※別のページを使いたい場合は 設定→基本設定→「お問い合わせページ」で選べます。


■ ショートコード（デザインパターン）
   [eamber_form]                  標準。全項目・枠なし。幅は設定値（既定680px）で中央寄せ
   [eamber_form design="compact"] 必須項目のみ・幅440pxのカード
   [eamber_form design="card"]    全項目を枠＋影のカードで表示
   属性: button="ボタン文言"

   ■ ティザー（記事に置く入口フォーム）
   [eamber_form design="teaser"]    横長。入力欄が横一列に並ぶ
   [eamber_form design="teaser-v"]  縦。常に縦積み（幅440px）

   横長は「工事内容」「市町村」などを横一列に並べます。幅が足りなく
   なると自動的に縦積みへ切り替わるので、スマホでもそのまま使えます。

   2〜3項目だけ聞いて、続きはお問い合わせページで書いてもらう形です。
   入力内容はお問い合わせページに自動で引き継がれ、「↓ 続きはこちらから」と
   案内して次に書く欄まで自動でスクロールします（あと何項目かも表示）。
   工事内容はタイルを1タップで選べます。

   属性:
     url      遷移先。ふだんは書かなくて構いません（設定→基本設定→
              「お問い合わせページ」で選んだページへ送ります）。
              そのフォームだけ別のページへ送りたいときに指定します
              例: url="https://kai-denkou.com/contact/"
     fields   聞く項目と順番。ptype（工事内容）/ address（市町村）/
              timing（希望時期）から選ぶ。省略時は ptype,address
              ※お名前・電話番号・メールはティザーには置けません。
                個人情報は、利用目的の明示と同意チェックがある
                お問い合わせページで受け取る決まりにしているためです。
     width    横幅。ティザーだけでなく標準・カード・コンパクトにも使えます。
              数字だけならpx（例 width="720"）、width="100%" も可。
              省略時は 標準/カード＝設定「フォームの横幅」（既定680px）、
              ティザー横長＝本文いっぱい、ティザー縦/コンパクト＝440px。
              いずれも中央寄せです。
     title    見出し（省略時: 60秒でかんたん入力）
     subtitle 小見出し
     badge    見出しのバッジ（ふだんは「デザイン」タブで設定）
     tags     メリットのタグ。カンマ区切り
              例: tags="見積り無料,県内同一料金,相談だけOK"
     steps    steps="0" で STEP 表記を消す
     logo     見出しの左のアイコン画像URL
     note     フォーム下の注記。| で改行
              例: note="しつこい営業はいたしません|見積りは無料です"
     button   ボタンの文言（省略時: 無料で相談する）


■ そのまま使える例
   記事の途中に置く:
     [eamber_form design="teaser"]
   サイドバーに置く:
     [eamber_form design="teaser-v"]
   エリア記事の見出しを地域に合わせる:
     [eamber_form design="teaser" title="甲府市の電気工事を相談する" subtitle="ご入力は60秒。しつこい営業はいたしません"]
   希望時期も聞く（横一列に3項目）:
     [eamber_form design="teaser" fields="ptype,address,timing"]
   お問い合わせページ本体（遷移先のページに貼る）:
     [eamber_form]


■ ティザーの引き継ぎについて
   ティザーの入力値は sessionStorage で引き継ぎます。URLのクエリに載せないのは、
   入力内容がブラウザ履歴や外部サイトへのリファラに残らないようにするためです。


■ スプレッドシートへの転記（連携タブ）
   反響が届くたびに、Googleスプレッドシートへ1行ずつ追記します。
   Google Apps Script を経由する方式です（Sheets APIの鍵をWordPressに置かないため、
   管理も、万一のときの被害も軽くなります）。

   つなぎ方:
     1. 連携タブで「合言葉」を決めて保存（貼り付け用スクリプトに自動で入ります）
     2. スプレッドシートを開き、拡張機能 → Apps Script
     3. 出ているコードを消して、連携タブのスクリプトを貼り付けて保存
     4. デプロイ → 新しいデプロイ → ウェブアプリ
        （次のユーザーとして実行＝自分／アクセスできるユーザー＝全員）
     5. 出てきたURLを「転記先のURL」に貼って保存
     6. 「転記する」をオンにして、接続テストを押す

   ★転記に失敗しても、お客様の受付は必ず完了します。
     転記できなかった分はWordPress側に残り、連携タブの「未転記」から
     まとめて送り直せます（最大50件ずつ）。
   ★「アクセスできるユーザー＝全員」でないとWordPressから書き込めませんが、
     URLは推測できない文字列で、合言葉が一致しない書き込みは弾かれます。

   ★あとから入力項目を増やしたり減らしたりしても、シートの列はずれません。
     列は最初から全項目ぶん用意してあり、隠している項目はその列が空になるだけです。
     ただし工事内容ごとの質問（設置する階・症状など）は個別の列ではなく
     「詳細」列にまとめて入ります（工事内容で聞くことが変わるため）。

   うまくいかないとき（上から順に確認）:
     1. 転記先のURLの末尾が /exec か（/dev では届きません）
     2. デプロイの「アクセスできるユーザー」が「全員」か
     3. スクリプトを直したあと、デプロイし直したか（保存だけでは反映されません）
     4. 連携タブの合言葉と、スクリプト1行目の SECRET が同じか
     5. スプレッドシートを開いた状態の Apps Script か（別プロジェクトだと別のシートに書きます）

   送る内容: 受付日時／工事内容／市町村／お名前／フリガナ／電話番号／メール／連絡希望時間帯／
             建物の種類／持ち家・賃貸／希望時期／症状・ご希望／詳細／送信元ページ／ID
   ※「送信元ページ」は、どの記事から問い合わせが来たかの記録です。CSVにも出ます。


■ 設定タブの構成
   基本設定       : 会社名（サイト名）・電話番号・電話案内の文言・問い合わせメール・
                    所在地・お問い合わせページ・送信元/通知先メール・プライバシーポリシーURL
   入力項目       : 項目ごとの必須/任意/非表示、スパム対策、ステップ表示
   自動返信メール : 件名・本文テンプレート、テストメール送信
   デザイン       : フォームの横幅、タイルの配色（3パターン）、ティザーの見出し、
                    フォームの色、電話案内の色、次に入力する欄の色
   連携           : スプレッドシートへの転記
   ショートコード : 貼り方と属性の一覧


■ タイルの配色（3パターン）
   設定→デザイン→「配色パターン」で選べます。
     ブランド（既定）… 9枚を同じ淡い色にして、選んだ1枚だけをアンバーで際立たせる。
                        紺×アンバーのサイトになじむ落ち着いた見た目。
     やわらかアンバー … 全体を暖色でまとめる。ブランドより親しみが出る。
     カラフル         … 内容ごとに9色。探しやすさは最大だが賑やかになる。
   どのパターンでもアイコンと代表例は出るので、色が無くても見分けはつきます。

   色そのものは「フォームの色」で変えられます。役割を分けてあります。
     ブランドカラー（既定 #1E3050 紺）… 画面の骨組み。必須の印・見出しの丸・入力中の枠
     ボタンの背景色（既定 #E8A33D アンバー）… 行動をうながす色。送信ボタンと進み具合のバー
   電話案内の帯（背景色・線の色・文字色）も個別に選べます。
   線の色を背景と同じにすれば、枠線を消したように見せられます。

   ※ボタンの文字色の既定は紺です。アンバーに白文字はコントラストが 2.4:1 しかなく
     沈むためで、紺なら 6.1:1 で確実に読めます。サイトのボタンと完全にそろえたい
     場合だけ #ffffff にしてください。


■ フォームの横幅
   本文幅が広いテーマだと、工事内容のタイルが1枚ずつ大きくなり、
   一覧としてひと目で見渡せなくなります。
   設定→デザイン→「フォームの横幅」で絞ってください（既定680px・中央寄せ）。
   そのフォームだけ変えたいときはショートコードに width="820" を足します。

■ ステップ表示（お問い合わせページ）
   お問い合わせページのフォームは「お困りの内容（概要）→ ご連絡先（個人情報）」の
   2ステップに分けて表示できます（既定ON。入力項目タブで切り替え）。
   進み具合のバーが出て、「次へ進む」を押すたびにその画面の必須項目だけを
   確認します。お名前・電話番号は必ず最後のステップで聞きます。
   ティザーで入力済みのステップは自動で飛ばします。

■ 常に必須の項目（切り替え不可）
     工事内容・現場の市町村・同意チェック
   メールアドレスは常に任意です（入力があれば受付完了メールを送る）。
   それ以外はすべて「入力項目」タブで必須/任意/非表示を選べます。
   既定で非表示の項目（持ち家か賃貸か・いつから・連絡方法・型番・年式ほか）は
   「入力項目」タブでいつでも復活できます。

   お客様に読ませる同意は「プライバシーポリシーに同意します」の1つだけです。
   免責事項への同意も、個人情報の説明文も、営業案内メールのチェック欄もありません。
   ★利用目的はプライバシーポリシーでの公表で足りるため、フォーム上での再掲はしません。
     プライバシーポリシーのURLは必ず設定してください（同意チェックからリンクします）。
   ★宣伝・キャンペーンのメールを送る予定ができた場合は、別途「送ってよいか」の同意が
     必要です（特定電子メール法はオプトイン方式で、プライバシーポリシーへの記載では
     同意になりません）。問い合わせへの返信・見積り・工事の連絡は同意不要です。


■ 受付内容の確認
   左メニュー「電気工事反響フォーム → 反響一覧」
   - 最新200件を表示。CSVエクスポート（Excel向けShift_JIS）
   - 1件ずつ削除できます（個人情報の削除依頼対応）。

■ 問い合わせ後の動き
   1. メール入力があったお客様に受付完了メールを自動返信（「自動返信メール」タブで編集可）
   2. 通知先メール（担当者）に内容を通知（カンマ区切りで複数宛に送れます）
   3. 担当者がお客様へ連絡し、日程・見積りをご案内
      （メール未入力のお客様には電話で折り返す。完了画面にもその旨を表示）


■ スパム・濫用対策（常時）
   - ハニーポット＋送信までの経過時間（画像認証なし。お客様の操作はゼロ）
   - 同一IP: 1時間に5件まで／同一メール: 24時間に3件まで
   - キリル/アラビア/タイ文字を含む送信を拒否
   - URL入りの送信を拒否（★既定はオフ。店舗・事務所のお客様が自社サイトの
     URLを書いて送ってくることがあり、オンにすると黙って弾いてしまうため）
   - NGワード登録（入力項目タブ）

■ メールについて
   ★「送信元メール」と「通知先メール」は役割が違います。
     送信元（差出人）… 空欄のままで構いません。wordpress@（サイトのドメイン）として
                        送ります。受信できるメールボックスは不要です。
                        Gmail などのフリーメールを入れると送れません（gmail.com から
                        送ってよいサーバーに、このサーバーが入っていないため）。
                        どうしてもGmailを差出人にしたい場合は、「WP Mail SMTP」等で
                        Gmailアカウント経由の送信に切り替える必要があります。
     通知先（受け取り）… Gmail で構いません。
                        カンマで区切れば複数に送れます。
                        例: aaa@gmail.com, bbb@gmail.com
   - テストメールは宛先を指定して送れます。通知先メール（担当者）のアドレスを
     入れて試すと、実際に受け取る人に届くかが分かります。
   - テストメールが送れないときは、まず送信元を空欄にして試してください。
     それで送れるなら、差出人のアドレスが原因です。
   - 担当者への通知が送れなかった場合、管理画面に赤いお知らせが出ます。
     反響そのものは「反響一覧」に残っているので失われません。
   - 到達率のため WP Mail SMTP 等でSMTP送信にし、送信ドメインの
     SPF / DKIM / DMARC を設定してください（テスト送信ボタンあり）。
   - 受付完了メールの末尾には、「基本設定」タブの会社名・電話番号・
     問い合わせメール・所在地が署名として自動で入ります
     （本文テンプレートに書く必要はありません）。

■ 法的な注意
   - 氏名・電話番号という個人情報を取得するため、利用目的をフォーム上に
     明示しています（個情法21条）。
   - 自社対応の前提で、同意文には「ご本人の同意なく第三者に提供することは
     ありません」と明記されます。同意なく他社に渡すのは違法です（個情法27条）。
   - 公開前に弁護士等の確認を推奨します。


■ 自動更新
   GitHub 上の update.json を見て、新バージョンがあると WordPress 管理画面に
   「更新可能」バッジが出ます。設定画面の「更新を確認」ボタンで即時確認できます。
